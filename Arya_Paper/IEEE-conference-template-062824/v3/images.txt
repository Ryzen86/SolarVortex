FIGURE 5
-------------------------------------------------------------
Filename:    fig_cbam_architecture.png
LaTeX label: fig:cbam_arch
Title:       CBAM Dual-Attention Module Architecture (Stage 2)
Section:     Section IV -- Stage 2: Binary Quality Triage
Description:
  Architecture diagram showing the CBAM block as inserted
  after the final convolutional stage of the backbone.
  Show two sequential paths:
  PATH 1 -- Channel Attention:
    Input feature map F (C x H x W)
    --> Global Average Pool (1x1xC) + Global Max Pool (1x1xC)
    --> Shared MLP (FC: C -> C/r -> C with ReLU)
    --> Element-wise sum
    --> Sigmoid -> M_c (channel attention map)
    --> F' = M_c (x) F  (channel-recalibrated features)
  PATH 2 -- Spatial Attention:
    F' (C x H x W)
    --> Channel-wise AvgPool (1 x H x W) + MaxPool (1 x H x W)
    --> Concatenate (2 x H x W)
    --> Conv2D 7x7 -> Sigmoid -> M_s (spatial attention map)
    --> Output = M_s (x) F' (final attended features)
  Annotate with feature map shapes at each step.
  Use consistent colour scheme: blue = convolution,
  orange = pooling, green = attention map.
Source:
  Create as vector graphic (Inkscape / draw.io / TikZ).
  Reference: Woo et al., ECCV 2018 (CBAM paper, Fig. 1).

 NOTES FOR ALL FIGURES
=============================================================
- All figures must be saved at minimum 300 DPI for print quality.
- Preferred format: PNG (for raster outputs from notebooks)
  or PDF (for vector graphics to avoid pixelation).
- IEEE two-column format: single-column figures use \columnwidth
  (~88 mm); double-column figures use \textwidth (~180 mm).
- Keep figure file sizes reasonable (< 2 MB each) for PDF compilation.
- All figure files should be placed in the SAME directory as
  iSPEC2026_SolarVortex.tex (v2 folder) before compilation.
- Figure filenames as listed above must match exactly the
  \includegraphics{...} commands in the .tex file.
- After generating figures, update the paper .tex file to
  add any figure cross-references where indicated by comments.
